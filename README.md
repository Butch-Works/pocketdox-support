# PocketDox Support

Public support website and privacy policy for PocketDox for iPhone.

- App Store: https://apps.apple.com/us/app/pocketdox/id6823854425
- Support page: https://butch-works.github.io/pocketdox-support/
- Privacy policy: https://butch-works.github.io/pocketdox-support/privacy.html

Enable GitHub Pages in **Settings → Pages → Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, then save.

**Maintenance:** Keep the published privacy policy aligned with the distributed app and App Store Connect privacy answers, and configure a private support contact method. Public GitHub issues are not appropriate for sharing sensitive documents.

## App preview images

The support page includes a responsive, non-scrolling five-screen grid gallery in `index.html` (`#explore`). The optimised WebP assets live in `assets/screenshots/`. Keep image descriptions and the sample-data disclaimer current when replacing screenshots. The App Store download link is in the hero and footer. The support FAQ remains at `#questions`, and no JavaScript or build step is required.
